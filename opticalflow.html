01 · Overview

Classical computer vision vs deep learning

A comprehensive examination of optical flow estimation using both classical computer vision techniques, such as the Farneback algorithm, and a deep learning model, FlowNet 2.0, comparing how accurately each one estimates motion.

02 · Approach

From flow field to tracking

  1. Estimate optical flow with the classical Farneback algorithm and with FlowNet 2.0.
  2. Visualise the obtained flow as a grid of arrows.
  3. Track faces with a Haar-Cascade classifier.
  4. Analyse the optical flow field for both the velocity of movement and its direction.
  5. A user interface for the classical approach lets users visualise optical flow with different step sizes and reset the region of interest.

03 · Evaluation

How the two were compared

The comparison hinges on three performance metrics: L1 error, average endpoint error and average angular error. The analysis also evaluates flow discontinuity, velocity estimation, object tracking and pixel displacement, and performs bounding box analysis.

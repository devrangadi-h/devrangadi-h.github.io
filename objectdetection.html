01 · Overview

Recognising objects from a live webcam

A robust object classification system that processes video frames to classify 15 different objects from a live webcam video stream. It leverages K-Nearest Neighbor classification to achieve 95% accuracy.

The project performs 2D object recognition on the image sequence from a webcam: it isolates objects placed in view on a white surface, and is translation, scale and rotation invariant.

02 · Approach

From raw frames to a label

  1. Pre-process the incoming video stream by thresholding.
  2. Clean the thresholded frames by applying morphological operations.
  3. Isolate each object placed on the white surface, independent of its position, scale and rotation.
  4. Classify each object with K-Nearest Neighbor classification.

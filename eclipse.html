01 · Overview

Disaster response autonomous hexacopter

The Eclipse is an industrial-grade autonomous UAV spanning 1000 mm, capable of producing over 22 lbs of thrust and equipped with several sensors.

I was one of the core members of Project Jatayu at RV College of Engineering in Bangalore, the team that built The Eclipse and flew it at AUVSI SUAS 2019. That project got me hooked on autonomy.

02 · Capabilities

What it was built to do

  1. Surveying
  2. Static obstacle avoidance
  3. Target classification
  4. Air delivery, with a parachute delivery prototype

Built with C++, Python and OpenCV on PX4 and a Pixhawk 2.4, using MavLink, MavProxy and MavROS.
